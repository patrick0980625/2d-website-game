# 2d Website Rpg Game

This repository is just the code, because the texture is bought from itch.io, and the license said that I can't republicize them.

## Introduction

The game is about 5 minutes long, with a final boss to defeat.
You cannot play the game through these files, since the incompletion of texture.

There are some enemies and npcs in the game
- Goblin Archer
- Goblin Maceman
- Goblin Thief
- Orc Chief
- Slime
- Boss, a broccoli chicken

Scene:
- initial room and world
- village and some houses
- a decorative harbour
- forest with maze and enemies
- a cave to connect to castle
- castle with boss inside

## Handle

- WASD and arrows can move player
- press SHIFT when move can run
- mouse left click to attack
- mouse right click to dodge
- space to jump
- E to interact (open door, pick up items, talk to npc...)
- ENTER to close talk box
- F to pay respects

## Other

The game is made with JavaScript and Phaser.js
Maps are made with TileMapEditor
